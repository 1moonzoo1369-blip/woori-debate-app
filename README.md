# 우리교실, 토론앱 — 소개·다운로드 웹사이트

HTML·CSS·JavaScript만 쓰는 정적 웹사이트입니다. 서버 프로그램이나 빌드 과정이 필요 없어요.

```
index.html                               소개 페이지 (PC·휴대폰 대응, 밝은·어두운 화면)
img/                                     화면 사진, 아이콘
downloads/woori-debate-app-windows.zip   배포용 앱 (Windows)
.nojekyll                                GitHub Pages가 파일을 그대로 쓰게 하는 표시
```

## 앱을 새 버전으로 바꿀 때
`downloads/woori-debate-app-windows.zip` 파일만 같은 이름으로 바꿔 올리면 됩니다. 파일 크기가 크게 바뀌면 `index.html`의 "ZIP 2.9 MB" 문구도 고쳐 주세요.
